Snapshots from the distilled rulebooks

Lightly condensed excerpts; the complete rulebooks are in the companion repository.

Bridge

  1. Name every object by the shortest common word an ordinary person would use — the everyday name, never a description, riddle, or category phrase.
  2. Never swap one common noun for a common sibling: keep the input's plate (not dish), wheel (not tire), towel (not cloth).
  3. Banned verb family — always replace with 'put': move, transfer, shift, relocate, convey, transport, carry, deposit, position.
  4. When the spatial wording is anything else ('over to', 'until it makes contact with') or missing, translate by geometry: object ends up inside an open container -> 'in'; rests on top -> 'on'.
  5. Never delete the particle 'down' — 'put the coke down on the plate' is a top-measured form; 'down' is not an adverb to strip.
  6. Default is copy: if no trigger fires, output the input unchanged — do not swap, add, or delete any word.

LIBERO

  1. Replace 'hot plate', 'hotplate', 'burner', 'cooktop', 'stovetop' by 'stove', whatever name the scene description uses for the appliance.
  2. Never replace a specific name with a broader class or packaging word ('ketchup' must not become 'sauce' or 'bottle'); never shorten a compound name ('tomato sauce', 'orange juice' stay whole).
  3. Write the object's plain product or kind name as one would say it aloud (the ketchup, the orange juice, the moka pot), dropping packaging words.
  4. 'turn on', 'power on', 'fire up', 'ignite', 'light' all become 'switch on'.
  5. 'up onto', 'atop', 'on the top of' become 'on top of' when the destination is a fixture (cabinet, shelf, counter) and 'on' when it is a movable surface (plate, rack, stove); 'onto' becomes 'on', 'into' becomes 'in'.
